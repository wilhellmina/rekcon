# Reckon

日本語 | [English](README.en.md)

iPhone をホイールの面に当てるだけで、トー(とキャンバー)を測る Web アプリの試作。
普段の糸張り測定と比べて、精度が実用になるかを確かめるためのもの。

名前は dead reckoning(推測航法)から。iPhone を持って車の周りを歩く動きも、測定の一部になる。

## いまの状態

フェーズ1(前輪のトータルトーと、1輪ずつのキャンバー)まで。実機での精度の確認はこれから。
フェーズ2(繰り返し測定・ループ閉合・CSV)とフェーズ3(4輪・スラストライン)は [CLAUDE.md](CLAUDE.md) を参照。

## 使い方

トーとキャンバーは別々に測る。画面の上で選んでから「センサー開始」を押し、センサーの使用を許可する。

iPhone は、リムの縁に当たる治具に固定する。背面を当て、画面を車の外側に向けて止めておくと、ピッと鳴って記録される。
ケースは外すか、毎回同じ状態にする。

**トー**
1. リムの前と後ろの2点に当たる横向きの棒を、水平にして左前輪に押し当てる(傾けて立てかけると誤差が出る)。
2. 記録されたら、棒を裏返さずに車の前を回り、右前輪に同じように当てる。ピピッと鳴って結果が出る。
3. 移動は手早く(目安 15 秒以内)。時間が長いほど、ずれ(ドリフト)が溜まる。

**キャンバー**
1. リムの上と下の2点に当たる縦向きの棒を、測りたい輪に当てる。1輪ずつ測れる。
2. 棒を上下逆にしてもう1回測ると、iPhone の付け方の傾きが消える(任意)。
3. 床の傾きがそのまま効くので、平らな場所で測る。

## 動かし方

`index.html` の1ファイルだけ。ビルドも外部のライブラリもない。

- 端末は iPhone の Safari だけを考えている
- 画面は日本語と英語。右上で切り替えられる(最初は端末の言語)
- センサーは HTTPS でないと使えない。GitHub Pages の https://wilhellmina.github.io/rekcon/ で開く
- iPhone ではコンソールが見られないので、生のセンサー値やエラーは画面下のデバッグパネルに出る
