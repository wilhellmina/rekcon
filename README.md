# Reckon

日本語 | [English](README.en.md)

iPhone をホイールの面に当てるだけで、トー(とキャンバー)を測る Web アプリの試作。
普段の糸張り測定と比べて、精度が実用になるかを確かめるためのもの。

名前は dead reckoning(推測航法)から。iPhone を持って車の周りを歩く動きも、測定の一部になる。

## いまの状態

フェーズ1(前輪のトータルトー)まで。実機での精度の確認はこれから。
フェーズ2(繰り返し測定・ループ閉合・CSV)とフェーズ3(4輪・スラストライン)は [CLAUDE.md](CLAUDE.md) を参照。

## 使い方

1. 治具(リムの縁に当たる L字や平板)に iPhone を固定する。ケースは外すか、毎回同じ状態にする。
2. Safari で開いて「センサー開始」を押し、センサーの使用を許可する。
3. 左前輪に iPhone の背面を当てる(画面は車の外側)。止めておくとピッと鳴って記録される。
4. 車の前を回って右前輪へ。同じように当てて止めると、ピピッと鳴って結果が出る。
5. 移動は手早く(目安 15 秒以内)。時間が長いほど、ずれ(ドリフト)が溜まる。

## 動かし方

`index.html` の1ファイルだけ。ビルドも外部のライブラリもない。

- 端末は iPhone の Safari だけを考えている
- センサーは HTTPS でないと使えない。GitHub Pages の https://wilhellmina.github.io/rekcon/ で開く
- iPhone ではコンソールが見られないので、生のセンサー値やエラーは画面下のデバッグパネルに出る
